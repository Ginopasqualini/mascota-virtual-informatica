# Imágenes de la mascota

Copiá aquí las cuatro imágenes que enviaste y renombrá los archivos exactamente así:

- `normal.png`: erizo sonriendo.
- `feliz.png`: erizo con los brazos arriba.
- `llorando.png`: erizo llorando.
- `bostezando.png`: erizo bostezando.

La carpeta debe quedar así:

```text
img/
├── normal.png
├── feliz.png
├── llorando.png
└── bostezando.png
```

## Cómo guardar las imágenes desde Windows
1. Creá una carpeta llamada `img` en la misma carpeta donde está `main.py`.
2. Guardá o copiá las cuatro imágenes dentro de esa carpeta.
3. Renombrá cada archivo con los nombres indicados arriba.
4. En VS Code ejecutá:

```powershell
python main.py
```

> Las imágenes adjuntas en el chat no pueden convertirse automáticamente en archivos binarios dentro de GitHub desde esta herramienta. Por eso deben copiarse manualmente en `img/`. El programa está preparado para usarlas con esos nombres.
